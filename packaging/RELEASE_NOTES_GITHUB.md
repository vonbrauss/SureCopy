SureCopy 0.2.0 for Apple Silicon Macs (macOS 14 or later). Python and Qt are bundled.

**Install:** unzip, move SureCopy.app to Applications, then Control-click it and choose Open the first time. The app is ad hoc signed, not notarized.

Queue sources, copy them to several destinations at once (local drives, RAIDs, SMB shares, Avid Nexis), stop any time and pick up where you left off.

Job history lives in `~/Library/Application Support/SureCopy`. Verify the ZIP with the attached `.sha256` file if you like.
